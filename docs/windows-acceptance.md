# Ручная приёмка Windows

Этот список — инструкция, а не утверждение о пройденной проверке.

- Открыть EXE на Windows x64 с WebView2. Проверить окно, иконку и изменение размеров. Повторный обычный запуск должен открыть работающий экземпляр; `--background` не должен показывать окно.
- Создать тему и две заметки с разными датами; сменить обе сортировки, ручной порядок и закрепление. Сменить тему, поиск, закрыть/открыть приложение. Текст и порядок должны сохраниться.
- Начать редактирование и сразу сменить заметку/закрыть окно. После открытия проверить последний текст. При ошибке записи приложение должно сохранить редактируемый черновик и показать ошибку.
- В календаре создать созвон 09:00–10:00 и тренировку 12:00–13:30. Перенести/растянуть блок, переключить месяц/неделю/день. Проверить событие через полночь.
- Прикрепить существующую заметку и создать новую из карточки. Открыть связанную заметку. Удаление задачи сохраняет обе заметки; удаление заметки убирает её связь.
- Выбрать папку OneDrive. После редактирования проверить законченный JSON, наличие старых версий, отсутствие ключа Gemini; статус облачной загрузки смотреть в OneDrive. Недоступная папка не должна мешать локальному сохранению.
- Восстановить копию с подтверждением; проверить локальную recovery-копию. Некорректный JSON/неизвестная версия/битые ссылки должны отклоняться без замены данных.
- Ввести собственный Gemini key, открыть новую сессию. Проверить русскую речь и последнюю фразу при остановке; текст не должен вставляться без кнопки. Отмена не меняет заметку. Перезапуск приложения сохраняет ключ только в Credential Manager.
- Проверить отсутствие микрофона/разрешения, недействительный ключ и обрыв сети. Ошибки должны быть видны, скрытого перезапуска записи быть не должно.

Запуск с настоящим ключом передаёт звук Google и расходует квоты. Автотесты этого не делают.

## Оформление и UX

- Переключить светлую, тёмную и системную тему; перезапустить EXE. Проверить оформление заголовка окна Windows, выпадающих меню, диалогов, календаря и полей ввода. Смена темы Windows должна обновлять системный режим.
- Открыть тему и заметку правой кнопкой и через «…». Удалить другую заметку, не теряя текущий черновик. Переименование темы должно сразу фокусировать её название.
- Набрать Markdown с заголовком, таблицей и блоком кода; переключить редактор/просмотр и вернуться без потери текста. Ссылки http/https/mailto открываются системным обработчиком; raw HTML и автоматическая загрузка изображений отключены.

## Фоновая работа и релизы

- Изменить заметку и сразу нажать крестик/Alt+F4: окно исчезает, процесс и значок остаются. Открыть двойным щелчком по трею и проверить последний текст. Открытая изменённая карточка задачи/темы должна остаться; голосовая запись останавливается, текст остаётся. При недоступном диске окно не должно скрыться.
- Выбрать «Выход» в трее: приложение сохраняет заметку и завершается; при открытой карточке/голосовом черновике запрашивает подтверждение. Отмена сохраняет приложение и черновик. После отмены крестик по-прежнему только скрывает.
- Нажать/отпустить одиночный Alt: меню перемещения не появляется. Alt+Space открывает системное меню, Alt+Tab переключает окна. Видимое окно есть на панели задач и в Alt+Tab.
- Перезапустить Explorer при скрытом приложении: значок возвращается с прежним числом непрочитанных. В случае отказа трея окно должно показаться и разрешить обычный выход.
- Создать задачу с относительным и абсолютным напоминанием на ближайшие минуты; проверить звук/тихий режим, системное сообщение, красный индикатор и tooltip в трее, мигание открытого окна. Щёлкнуть по сообщению, открыть задачу из списка и прочитать все. Проверить светлую/тёмную панель задач и DPI 100/150/200%.
- Усыпить ПК на время напоминания и возобновить: пропуски последних 24 часов появляются одним сгруппированным сообщением и отдельными строками списка. Перезапуск не повторяет их; пропуски старше 24 часов не показываются. Повторить при закрытом процессе. Windows Focus/Do not disturb может подавлять внешний сигнал, но список сохраняется.
- Перенести задачу, отметить завершённой, удалить: новые напоминания соответствуют актуальному состоянию. Старые уведомления о перенесённой задаче не меняют время задним числом. Удаление задачи удаляет её уведомления.
- Включить автозапуск, выйти из Windows и войти: значок есть, окно скрыто. Открыть из трея. Выключить автозапуск и повторить вход. Переместить EXE, заново включить опцию и проверить новый путь. Тестировать только на своей учётной записи.
- Открыть базу v1 новой версией и импортировать JSON v1/v2: заметки сохраняются, напоминания v2 восстанавливаются. При импорте история уведомлений очищается и действует catch-up 24 часа. Неизвестная версия отклоняется.
- Скачать EXE/ZIP/SHA256SUMS.txt из GitHub Release. Проверить обе суммы (например, `Get-FileHash -Algorithm SHA256`), наличие notices/licenses/docs в ZIP и запуск EXE. CI/native unit tests не заменяют эти ручные сценарии.
