# Daynote: редактор Markdown

Статус: реализовано и проверено автоматическими и браузерными проверками.

Пользователь запросил полноценный редактор Markdown и автоформатирование
при сохранении, подтвердил Markdown-код с панелью действий и сохранение
существующих отдельных вкладок «Редактор» и «Просмотр».

Решения исполнителя: CodeMirror 6 вместо textarea, подсветка Markdown,
перенос строк, история отмены, поиск и панель: заголовок, жирный, курсив,
список, чек-лист, цитата, ссылка, код. Ctrl+B/I/K работают в редакторе.
Интерфейс и обе темы сохраняются. Новый документ получает собственную
историю; сохранение текущего документа не пересоздаёт editor view.

Prettier standalone с Markdown parser форматирует текст перед явным
сохранением и переходами из заметки. Сохраняются переносы абзацев
(`proseWrap: preserve`), содержимое code fences не форматируется
(`embeddedLanguageFormatting: off`). Пустой текст остаётся пустым.
Фоновое автосохранение 650 мс сохраняет сырой черновик: нормализация во время
паузы в наборе меняет незаконченный Markdown и мешает вводу. Это решение
сообщено пользователю до реализации.

Go остаётся владельцем хранения; форматирование — renderer-подготовка
перед существующим SaveNote, без изменения SQLite/backup. Все явные
сохранения через api.saveNote используют общий formatter; autosave
явно отключает его. Даже уже автосохранённая заметка форматируется перед
явным сохранением. Очередь сохраняется: ответ не заменяет более новый
черновик. Ошибка форматирования/сохранения сохраняет черновик и останавливает
навигацию. Панель редактирует выделение через транзакции CodeMirror;
форматирование и вставка голоса участвуют в undo. Форматирование не запускает
код из заметки и не отправляет содержимое в сеть.

Просмотр остаётся react-markdown/remark-gfm без raw HTML и внешней загрузки
изображений. Визуальный rich-text режим, split-screen и форматирование
языков внутри code fences не входят в изменение.
