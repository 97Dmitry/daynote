# Daynote: тёмная тема, Vite+ и UX

Запрос: добавить тёмную тему, перейти на Vite+, улучшить UX, обеспечить CI и Windows-сборку. Работа в текущем checkout; существующие заметки, задачи, голос и формат резервных копий сохраняются.

1. Vite+: штатная миграция CLI без изменения agent instructions/hooks; единый `vite-plus` config, `vp check/test/build`, команды Wails/Makefile/CI и актуальный lockfile. Проверка: существующие тесты и новая Windows-сборка.
2. Тема: светлая/тёмная/системная, настройка в Go settings.json с сохранением пути резервных копий. Кэш только UI-предпочтения для первого кадра; Go остаётся источником настройки. Календарь, диалоги, формы и статусы используют общие цвета. Проверка: перезапуск, независимость настроек, системное переключение, браузерные снимки обеих тем.
3. UX (уточнено пользователем): контекстные меню правой кнопкой и видимые действия тем/заметок, удаление без перехода в объект, крупнее интерфейс, Markdown с переключением редактор/просмотр. Темы остаются плоскими. Markdown не исполняет raw HTML; изображения автоматически не загружаются из сети.
4. CI: адаптировать существующий pipeline к setup-vp, сохранить Go/native Windows/browser проверки и скачиваемый EXE с checksum. Собрать и проверить локально. Не объявлять удалённый CI успешным без фактического завершения workflow для соответствующего commit.
