# Daynote Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Рабочее Windows-приложение заметок, календаря, голосового ввода и резервных копий.

**Architecture:** Go владеет SQLite-хранилищем, валидацией и записью/распознаванием. React вызывает типизированный Wails bridge; FullCalendar отображает расписание. Отдельный JSON-экспорт для OneDrive не содержит настроек и ключей.

**Tech Stack:** Go, Wails v2, React/TypeScript, Vite, FullCalendar, SQLite, WASAPI, Gemini Live.

**Spec:** `docs/superpowers/specs/2026-11-02-daynote-design.md`

## Global Constraints

- Windows x64, русский интерфейс, отдельное приложение и публичный `97Dmitry/daynote`.
- Solveo доступен только для чтения. Его пользовательские данные и ключи не переносятся.
- Рабочая база локально; OneDrive получает завершённые версионные JSON-копии.
- Ключ Gemini только в Windows Credential Manager, аудио не сохраняется.
- Проверка Windows-сборки не равна ручной проверке микрофона и интерфейса.
- Изменения в текущем checkout. Коммит/публикация только файлов Daynote в рамках явно запрошенного репозитория.

## Review Focus

- Смена заметки во время сохранения/распознавания не должна менять адресата текста — UI behavioral tests и review голосового черновика.
- Плохой импорт не заменяет существующие данные — транзакционный store test.
- Отказ OneDrive не ломает локальное сохранение — backup test с недоступной папкой.
- Перенос задачи через полночь сохраняет интервал — store interval test.
- Одновременный запуск не открывает двух владельцев базы/экспорта — Windows singleton и runtime checklist.

### Task 1: Данные и резервные копии

**Files:** `go.mod`, `internal/store/{model,store,backup}.go`, `internal/store/store_test.go`, `AGENTS.md`.

**Interfaces:** `Open(path string) (*Store,error)`, `Snapshot() (Snapshot,error)`, `SaveNote(Note)`, `SaveTopic(Topic)`, `SaveTask(Task)`, `Delete(kind,id string)`, `Move(kind,id string,delta int)`, `Export(dir string) (string,error)`, `Import(data []byte) error`. Все изменения возвращают актуальный snapshot через app.

- [ ] Написать тесты перезапуска, закрепления/порядка, ссылок на заметки, отрицательных интервалов, импорта и ошибок экспорта; запустить и увидеть отсутствие реализации.
- [ ] Реализовать SQLite с транзакциями и полной проверкой импорта до замены. Проверить существование ID и уникальность связей; дату заметки проверять как ISO date.
- [ ] Реализовать экспорт снимка через temp+rename и уникальные имена. Импорт предваряется локальной аварийной копией на app-уровне.
- [ ] Запустить `go test -race ./internal/store` до PASS.

### Task 2: Windows shell и голос

**Files:** `main_windows.go`, `main_bindings.go`, `app.go`, `internal/voice/*`, `internal/audio/*`, `internal/stt/*`, `internal/secrets/*`, `wails.json`, `Makefile`.

**Interfaces:** Wails-bound `App`: `Load`, `SaveNote`, `SaveTopic`, `SaveTask`, `Delete`, `Move`, `GetSettings`, `SetGeminiKey`, `ChooseBackupFolder`, `BackupNow`, `RestoreBackup`, `StartVoice`, `StopVoice`, `CancelVoice`. Voice events carry session ID and transcript/status; never API key.

- [ ] Изучить и перенести только микрофонный capture, Gemini transport и secrets из Solveo с заменой module/import и credential prefix; проверить имеющиеся fake transport tests.
- [ ] Реализовать lifecycle одного окна, singleton и одной голосовой сессии; flush перед закрытием, отмена без вставки в заметку.
- [ ] Сделать автоматический backup worker с debounce; ошибки экспортировать в status. При завершении дождаться остановки worker/capture.
- [ ] Генерировать bindings headless entrypoint, без Windows GOOS для генератора.
- [ ] Запустить Go tests и Windows vet.

### Task 3: Пользовательские сценарии

**Files:** `frontend/src/{App,Notes,Calendar,Settings,Voice}.tsx`, `frontend/src/{api,types}.ts`, `frontend/src/styles.css`, frontend config/lockfile, generated `frontend/wailsjs`.

**Interfaces:** Types соответствуют Go JSON DTO; `api` вызывает только Wails. Запросы изменения сериализуются, редактор хранит черновик до подтверждения сохранения.

- [ ] Создать React/Vite frontend, установить зафиксированные зависимости; календарь использовать готовый, иконки lucide.
- [ ] Темы/поиск/закрепление/сортировки/перестановки и редактор с автосохранением и защитой смены заметки.
- [ ] Календарь с интервалами и карточкой задачи; связи с существующими/новыми заметками. Ошибки drag/resize откатывают optimistic change.
- [ ] Настройки Gemini/OneDrive/восстановления и отдельный голосовой черновик. Доступные подписи кнопок и клавиатурные формы.
- [ ] Behavioral tests через mock bridge: создание заметки/задачи, сохранение перед переходом, прикрепление и черновик записи. `pnpm test`, typecheck и build до PASS.
